# ChobiDeh — PC SignIn & SignUp Sliding Panel

A standalone, modern, responsive authentication screen designed for desktop PC featuring a slow, smooth hardware-accelerated **sliding panel transition** (1.15s ease) between Sign In and Sign Up.

## ✨ Features
- **Slow Sliding Panel Animation**: Smooth 1.15s cubic-bezier deceleration where the Form Card and Archival Showcase glide and swap places dynamically.
- **Layerable 3D Cloud Vault**: High-resolution floating polaroid memory cards with ambient glow halo, sparkles, and live status badge.
- **Curated Mint Aesthetics**: Premium typography (`Outfit`, `Plus Jakarta Sans`, `Caveat` cursive script) and harmonious emerald/mint palette.
- **Interactive Controls**:
  - Show/Hide Password toggles
  - Interactive Feature Pills with animated toast hints
  - Google Sign-In and Sign-Up integration buttons
  - Responsive layout for PC, laptops, and mobile screens

## 🚀 How to Run Locally
Simply open `index.html` in any web browser, or serve with any static server:
```bash
npx serve .
```
or double-click `index.html`.
